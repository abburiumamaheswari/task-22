Veda Technology – Data Science Internship

To understand and implement Pandas `groupby()` operations for summarizing numerical data across different categories.

## Tools Used

- Jupyter Notebook / Google Colab

## Concepts Covered

- GroupBy using Mean
- GroupBy using Count
- GroupBy using Minimum and Maximum

- Multiple Aggregation Functions

2. Department-wise average salary.
3. Employee count by department.

6. Multiple aggregation functions using `agg()`.
